# Changelog

## 0.1.0

Initial source release of the live-state integration.

- Main menu, episode browser, gameplay and pause presence.
- Live episode and scene/script metadata; optional runtime chapter display.
- Cover art, optional episode assets and session timer.
- Local sidecar builds, guarded install/uninstall and launch-scoped companion.
- Portable configuration, synthetic tests, Lua mocks and CI.

Game-derived outputs, artwork, personal configuration and local research artifacts are intentionally excluded.
